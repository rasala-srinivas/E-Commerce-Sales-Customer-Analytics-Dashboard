# E-Commerce Sales & Customer Analytics Dashboard

## Project Overview
This project focuses on analyzing e-commerce sales performance, customer behavior, product trends, and delivery metrics using Microsoft Excel.

## Business Objective
To provide business stakeholders with a centralized dashboard for monitoring sales performance, customer engagement, product demand, and delivery efficiency.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Dashboard Design

## Key Features
- Customer KPI Tracking
- Product Performance Analysis
- Sales Revenue Monitoring
- Delivery Performance Metrics
- City-wise Order Analysis
- Coupon Usage Analysis
- Top Customer Analysis
- Interactive Slicers

## Dashboard KPIs
- Total Customers
- Average Customer Age
- Total Orders
- Average Delivery Days
- Product Performance
- Revenue Metrics
- Discount Analysis

## Outcome
Developed an interactive Excel dashboard that transforms raw sales data into actionable business insights and supports data-driven decision-making.
